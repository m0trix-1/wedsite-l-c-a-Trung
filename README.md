# I'M WEB.BUILD — Coffee Shop Landing Page

Single-file website (`index.html`, all CSS/JS inline) — ready to publish on GitHub Pages.

## Deploy to GitHub Pages
1. Create a new repo on GitHub (e.g. `im-web-build`).
2. Upload `index.html` to the repo root (drag-and-drop on github.com works fine).
3. Go to **Settings → Pages**, set Source to `main` branch / `root`.
4. Your site will be live at `https://<your-username>.github.io/<repo-name>/`.

## What's included
- Sticky header with pill nav + cart counter
- Hero section with 3 switchable drink flavors (color, price, description all update live)
- Category-tabbed product carousel (Drinks / Food / AtHome / Merchandise)
- Product customization modal (size, sugar slider, quantity, live price)
- Full-bleed brand statement section with scrolling ribbon
- Popular products grid
- Scrolling marquee + contact form section
- Promo banners + footer

All drink illustrations are custom-built SVGs (no external images or trademarked logos), so it's fully self-contained and safe to publish as-is.
