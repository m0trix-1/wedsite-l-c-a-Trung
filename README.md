# ☕ The Cozy Bean - Website Cửa Hàng Cà Phê

Một giao diện trang web giới thiệu cửa hàng cà phê hiện đại, tối giản và mượt mà, được xây dựng bằng HTML, CSS và JavaScript thuần (Vanilla JS). Trang web đã được tối ưu hóa để triển khai nhanh chóng lên **GitHub Pages**.

## 🚀 Tính năng nổi bật
- **Responsive Web Design (RWD):** Hiển thị hoàn hảo trên các thiết bị Mobile, Tablet và Desktop.
- **Dynamic Menu:** Dữ liệu sản phẩm được tải động bằng JS, hỗ trợ lọc danh mục (Cà phê, Trà, Bánh) mà không cần tải lại trang.
- **Product Modal:** Xem chi tiết sản phẩm tiện lợi qua popup hiện đại.
- **SEO & PWA Ready:** Đi kèm đầy đủ file cấu hình robot, sitemap và manifest.
